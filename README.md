# Puvvala Naga Venkata Ganesh — Portfolio Recreation

Self-contained static recreation of https://my-awesome-folio-024.lovable.app/

Files:
- index.html — portfolio markup/content
- styles.css — responsive styling
- script.js — contact form mailto behavior

Open `index.html` directly in a browser, or serve the folder using any static web server.

The original Lovable source repository was not publicly exposed by the page, so this ZIP recreates the publicly rendered website rather than claiming to contain the original private source.
